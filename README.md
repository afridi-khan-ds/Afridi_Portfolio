## Featured Projects

### 1. SuperStore Sales Analytics & Forecasting

Developed an interactive Power BI dashboard to analyze SuperStore sales performance, including sales, profit, order volume, and delivery time. Explored performance across regions, product categories, customer segments, and shipping modes. Applied time-series forecasting to predict sales for the next 15 days with confidence intervals.

**Key Skills:** Power BI, Data Visualization, KPI Analysis, Time-Series Forecasting

### 2. Customer Churn Analysis & Retention Insights

Developed an end-to-end customer churn analysis project using Python, SQL, and Power BI. Analyzed customer behavior, explored churn drivers, assessed revenue risks, and developed insights to help businesses understand customer attrition and improve retention strategies.

**Key Skills:** Python, SQL, Power BI, Data Cleaning, Machine Learning, Predictive Analytics

### 3. HSE Incident Analysis & Safety Performance Dashboard

Created an HSE analytics dashboard using Microsoft Excel and Power BI to analyze workplace incidents and monitor safety performance. The dashboard tracks key safety indicators, including incidents, near misses, lost time injuries, and lost workdays. It also explores incident severity, event types, root causes, departments, and corrective action status to support data-driven safety improvements.

**Key Skills:** Microsoft Excel, Power BI, DAX, HSE Analytics, KPI Monitoring, Data Visualization

**GitHub Repository:** [HSE Incident Analysis Dashboard](https://github.com/afridi-khan-ds/HSE-Incident-Analysis-Dashboard)

### 4. Interactive Quiz Game

Developed an interactive multiple-choice quiz game using HTML, CSS, and JavaScript. The application features 10 general knowledge questions, randomized question order, question numbering, instant feedback for correct and incorrect answers, automatic score tracking, and a final results screen with a Play Again option.

**Key Skills:** HTML5, CSS3, JavaScript, DOM Manipulation, Event Handling, Front-End Development

**Live Demo:** [Play the Interactive Quiz Game](https://afridi-khan-ds.github.io/interactive-quiz-game/)
